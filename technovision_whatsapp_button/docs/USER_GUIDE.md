# User guide

Open a contact. If the number is usable, there is a **WhatsApp** button next
to it. Click it.

WhatsApp opens in a new tab, at `wa.me`, with the number already filled in.
Where that lands depends on the machine: the desktop app if it is installed,
WhatsApp Web if it is not, the app on a phone.

## What it does not do

* It does not send anything. It opens a chat; you type.
* It does not record anything. There is no log, because nothing happens
  inside Odoo.
* It does not contact WhatsApp. The link is built in Odoo and followed by the
  browser.

## When the button is not there

The number is not usable. The most common reason is a national number on a
contact with no country set - see CONFIGURATION.

## If you need to send from Odoo

Templates, delivery status, retries and a record of what was sent are
**TechnoVision WhatsApp Core**. This module is not a limited version of that
one; it is a different thing that happens to share a name.
