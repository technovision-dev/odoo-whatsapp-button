Simple WhatsApp Button

Opens the chat with the number already correct. Free, no account, no API.

The number is the whole problem

WhatsApp needs a number in international form — a country code, then the national number, with no spaces, brackets, dashes or leading zero. Almost no address book stores it that way, which is why a “WhatsApp button” so often opens a chat with nobody, or worse, with somebody else.

This module reads Mobile, falls back to Phone, strips the formatting, converts a 00 prefix, and applies the contact’s country dialling code when the number is written nationally.

And when the result would not be a valid number, the button does not appear at all. A button that does nothing is better than a button that opens the wrong conversation.

What it does with what you have

On the contact Button Why
+20 123 456 7890 shown Already international.
00201234567890 shown 00 is the international prefix.
01234567890 with a country set shown The dialling code is applied and the leading zero dropped.
01234567890 with no country hidden No way to know which country. Guessing opens a chat with a stranger.
+20 123 456 7890 ext 12 hidden An extension is not part of the number.
+2012 · call the office hidden Not a number.

Nothing leaves your Odoo

The link is built in Python and rendered into the page. Odoo never contacts WhatsApp; your browser goes to wa.me only when somebody clicks. No account, no API key, no telemetry, nothing recorded.

Nothing to configure

Install it and the button is there. It depends on base alone, adds one non-stored computed field, and uninstalls without leaving anything behind.

Free, and built like a paid one

18 automated tests, most of them asserting that no link is produced. Nine documents inside the module. LGPL-3, and the source is public on GitHub.
